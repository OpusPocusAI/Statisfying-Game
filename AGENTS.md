# Sea Glass Studio project context

Before working on this project, read [the original development prompt](Documentation/DEVELOPMENT_PROMPT.md) for the intended game, scope, and requirements, and [the implementation record](Documentation/IMPLEMENTATION.md) for recorded development context.

For any visual or art work, also read [the art direction](Documentation/ART_DIRECTION.md). It defines the target look, reference games, and the per-area quality bar, and replaces the development prompt's "stylized placeholders" art bar.

The development prompt is preserved as historical project guidance. Follow the user's current task and constraints; do not treat the original autonomous implementation request as authorization to resume development, modify files, build, commit, or push in every session. Verify the current project state rather than assuming all original requirements are implemented or all recorded results are current.
